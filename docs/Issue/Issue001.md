# Issue001: NBA Draft DBの目的とMVP構成の定義

## 背景

NBAでドラフトされた選手について、ドラフト年ごとにどのような選手が指名されたか、その選手がNBAで何シーズン活動したか、オールスターに何回選出されたかなどを集計・分析できるDBを作る。

ドラフト外選手も対象に含め、ドラフト指名選手とのキャリア傾向を比較できるようにする。

最終的には、Looker Studioで統計を可視化し、そのレポートを静的ページに埋め込んで公開する。

## 決定事項

### 対象範囲

- NBAドラフトで指名された選手を対象とする
- NBA公式戦に出場したドラフト外選手も対象とする
- NBAレギュラーシーズンを基本対象とする
- 現役選手を含める
- MVPではABA、海外リーグ、NBA以外の詳細実績は対象外とする

### キャリア年数

「何年残ったか」は、NBA公式戦に出場した異なるシーズン数を主指標とする。

また、以下を別の指標として保持する。

- NBA初出場シーズン
- NBA最終出場シーズン
- 初出場から最終出場までのキャリア期間
- 通算出場試合数

途中でNBAを離れた期間がある選手について、実際に出場したシーズン数とキャリア期間を区別する。

### オールスター

- オールスター選出回数と実際の出場回数を区別する
- 選出されたが欠場した選手は、選出回数には含める
- 欠場した選手は、実際の出場回数には含めない

### ドラフト外選手

ドラフト外選手は `draft_status = undrafted` とする。

ドラフト外選手の以下の項目はNULLとする。

- `draft_year`
- `draft_round`
- `overall_pick`

MVPでは、ドラフト外選手をNBA初出場シーズン別に集計する。将来、本来参加可能だったドラフト年を推定するかどうかは別途判断する。

## MVPの構成目標

MVPではCloudflare D1を使用しない。

リポジトリ内のSQLiteまたはCSVを正本データとし、そこから以下を生成する。

```text
正本データ（SQLiteまたはCSV）
        ├─ 集計CSVまたはGoogle Sheets
        │       └─ Looker Studio
        │
        └─ 静的JSON / CSV
                └─ Cloudflare Pages上の静的ページ
```

Google Sheets、Looker Studio、静的JSON、静的CSVを個別に手入力して更新しない。正本を更新した後、各出力を再生成する。

## MVPで扱う主なデータ

### 選手

- 選手ID
- 表示名
- 生年月日
- 国籍または出身国
- ポジション
- 外部データソースの情報

### ドラフト

- ドラフト年
- ドラフトラウンド
- 全体指名順位
- 指名チーム
- ドラフト区分

### シーズン

- シーズン
- 所属チーム
- 出場試合数
- 先発出場数
- 必要に応じた基本スタッツ

### 選出・受賞

- 選手
- シーズン
- 表彰・選出の種類
- 選出されたか
- 実際に出場したか

すべての外部データには、可能な範囲で以下を記録する。

- `source_name`
- `source_url`
- `retrieved_at`
- 外部ソース側のレコードID

## Looker Studioで実現する可視化

- ドラフト年ごとの選手数
- ドラフト年ごとの平均NBA活動シーズン数
- 指名順位と通算出場試合数の関係
- 1巡目、2巡目、ドラフト外の比較
- ドラフト年別のオールスター選出人数
- ドラフト外からオールスターに選出された選手
- 選手別のキャリアサマリー

## 静的ページで実現すること

- プロジェクトの概要を表示する
- Looker Studioレポートをiframeで埋め込む
- 指標の定義を表示する
- データの最終更新日時を表示する
- データソースと注意事項を表示する
- Cloudflare Pagesで公開する

## MVPロードマップ

### Phase 1: 要件とサンプルデータ

- 対象範囲と指標定義を確定する
- 代表的なドラフト年のサンプルを作る
- 選手IDと出典情報の方針を決める
- SQLiteまたはCSVの形式を決める

### Phase 2: 正本データと集計

- 基本テーブルを作る
- ドラフト情報を登録する
- シーズン情報を登録する
- オールスター情報を登録する
- キャリア集計を生成する
- 集計結果を検証する

### Phase 3: Looker Studio

- Looker Studio用CSVまたはGoogle Sheetsを生成する
- データソースを接続する
- 基本チャートとフィルターを作る
- ドラフト年、指名順位、ドラフト区分などで絞り込めるようにする

### Phase 4: 静的ページと公開

- 静的ページを作る
- Looker Studioレポートをiframeで埋め込む
- 更新日時と出典を表示する
- Cloudflare Pagesへデプロイする
- 公開環境でレポートを閲覧できることを確認する

## MVP完了条件

- 正本データから集計結果を再生成できる
- drafted / undrafted を区別できる
- ドラフト年、指名順位、NBA活動シーズン数、通算出場試合数、オールスター選出回数を確認できる
- Looker Studioで基本的な比較と絞り込みができる
- Looker Studioレポートを静的ページに埋め込める
- Cloudflare Pagesで静的ページを公開できる
- データの出典と最終更新日時を確認できる

## MVP後の方針

MVPでデータモデル、集計、可視化、公開の流れを検証した後、必要に応じてCloudflare D1を導入する。

将来は以下を追加候補とする。

- D1とCloudflare Workers API
- 選手検索・選手詳細ページ
- ドラフト年別ページ
- 定期データ更新
- 差分取得と更新検証
- プレーオフ成績
- All-NBA、MVPなどの受賞歴
- データ更新履歴と品質監視

詳細な将来計画は [将来ロードマップ](../future-roadmap.md) に記載する。
