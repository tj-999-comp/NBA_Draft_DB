# Looker Studio用データ生成
ドキュメント：[Issue008.md](https://github.com/tj-999-comp/NBA_Draft_DB/blob/main/docs/Issue/Issue008.md)

## 背景

集計結果をLooker Studioへ接続できる形式で出力し、正本から再生成できるようにする。

## 対象範囲

- 選手別キャリアサマリー
- ドラフト年別サマリー
- 指名順位別サマリー
- drafted / undrafted比較用データ
- オールスター選手一覧

## 完了条件

- Looker Studio接続用CSVまたはGoogle Sheets向けデータを生成できる
- 出力に更新日時と必要な出典情報が含まれる
- 手入力なしで正本から再生成できる

## 未決事項
